Enter the admin token to continue.

Where is it? On the very first start the server printed it in its console, and it is always saved in the file admin_token inside the server's data folder (data/admin_token unless you changed data_dir). If you set admin_token_env, it is that environment variable's value. It stays in this browser tab only.
